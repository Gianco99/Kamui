Archived documentation
======================

Studies and planning documents that are finished. Documents in docs/ are transient and live only as long as the work they describe; once that work is done, the document moves here rather than being deleted, so the reasoning behind old decisions stays recoverable.

How to archive a document
-------------------------

One subfolder per study, named for the study. Inside it, put the document itself and a README.txt containing:

  - what the goal of the study was
  - what was actually accomplished, including anything that did not work
  - who did it
  - the date, or date range
  - links: Evernote notes, the relevant git commits or PRs, presentations, anything else that would let someone reconstruct the context

The links matter more than the prose. A year later the document alone rarely explains why a choice was made; the PR discussion and the meeting notes usually do. Whoever is archiving rarely remembers them all unprompted, so if an AI helper is doing the archiving it should ask for them explicitly rather than leaving the section thin.
